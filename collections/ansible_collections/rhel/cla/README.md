# Ansible Collection - rhel.cla

Collection of roles and playbooks for self-managed RHEL CLA.

### Playbooks ###

**Installation**

- rhel.cla.local → Install RHEL CLA on a single local host.
- rhel.cla.install → Install RHEL CLA on one or more remote systems.
- rhel.cla.k8s [WIP] → Deploy RHEL CLA in a Kubernetes or OpenShift cluster. Still under development.


**Removal**

- rhel_cla.local_uninstall → Completely remove a local installation.
- rhel.cla.uninstall → Completely remove a remote installation.
- rhel.cla.k8s_uninstall [WIP] → Remove the deployment and supporting components. Still under development.
